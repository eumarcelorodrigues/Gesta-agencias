# Gesta-agencias

Este repositório contém um projeto de Business Intelligence em Power BI voltado para Gestão de Agências, com foco em análise de desempenho, indicadores estratégicos e apoio à tomada de decisão.

O projeto foi desenvolvido para transformar dados operacionais em insights claros, visuais e acionáveis, seguindo boas práticas de modelagem, visualização e governança de dados.
